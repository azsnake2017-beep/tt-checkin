# Правила участия в проекте ЧМЗ Настольный теннис

## Язык

- **Все коммиты, Pull Request и комментарии** оформляются на **русском языке**.
- Исключение: имена переменных, функций и комментарии в коде — на английском (стандарт индустрии).

## Формат коммитов

Используем **Conventional Commits** с русскими описаниями:

`
<тип>: <краткое описание на русском>
`

### Типы коммитов

| Тип | Когда использовать |
|-----|--------------------|
| eat | Новая функция |
| ix | Исправление бага |
| perf | Улучшение производительности |
| efactor | Рефакторинг без изменения функциональности |
| style | Изменения стилей/CSS |
| docs | Обновление документации |
| chore | Обновление зависимостей, конфигов |

### Примеры

`
feat: добавить экран турнирной сетки
fix: исправить баг подтверждения матча в одиночном разряде
perf: оптимизировать запрос истории матчей
style: обновить цветовую схему тёмной темы
docs: добавить инструкцию по развёртыванию
`

## Ветки

| Ветка | Назначение |
|-------|------------|
| main | Продакшн (стабильная версия) |
| dev | Разработка (ветвиться от dev) |
| ix/* | Хотфиксы |
| eat/* | Новые функции |
